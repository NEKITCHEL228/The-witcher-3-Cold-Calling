# Security & Asset Safety Standards

## 1. Secrets and Credentials
- Never commit API keys, personal tokens, or passwords to git.
- Keep `.gitignore` updated with local developer configs and editor temporary files (`.godot/`, `.import/` if generated locally).

## 2. Asset Integrity
- Use royalty-free or custom-created assets adhering to game jam rules.
- Strictly adhere to age rating rules: **NO 18+ content** (no explicit violence, gore, or sexual themes).
- Keep sound assets and textures compressed and lightweight to prevent memory bloat.
